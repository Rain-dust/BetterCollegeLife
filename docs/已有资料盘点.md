## 盘点如何决定选题

| 调研判断 | 选题落点 |
| --- | --- |
| 有成品和实读章节支持 | 生活优先写食堂、宿舍、校区设施和错峰，玩乐先写低门槛试社团、季节漫游、活动查询。历史个案用于设计步骤。 |
| 有现成索引，需要追溯原始出处 | 铁路学生票、软件教育许可、校内申诉、高职实习和研究生资格，逐项回 12306、供应商、教育部、研招网与当年学校文件。 |
| 有官方活动信息，缺学生使用反馈 | 柳州案例写到场截止和备用目的地，排队、公交和预约按当天实际确认。加入寝室附近、县城或偏远校区也可操作的校园内路线。 |
| 尚无足够来源 | 暂不做城市票价榜和社团名单排名。优先补高职在读经验、无障碍路线、夜间返校与近郊公交、校外档口真实花费。 |
