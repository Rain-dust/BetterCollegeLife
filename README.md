# 高性价比大学生活指南

给中国大学生的一份生活指南。想在食堂吃到喜欢的饭、周末去听一场演出、在寝室睡个好觉，或是留一晚上和朋友打球，这些都值得。想准备升学、实习、就业或者试试创业，也可以从一件小事开始。
