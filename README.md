# 高性价比大学生活指南

GitHub 发布用仓库名为 `BetterCollegeLife`。

给中国大学生的一份生活指南。想在食堂吃到喜欢的饭、周末去听一场演出、在寝室睡个好觉，或是留一晚上和朋友打球，这些都值得。想准备升学、实习、就业或者试试创业，也可以从一件小事开始。

**第一版 · 2026-11-18 · 40 条建议。** 其中 24 条讲日常和玩乐。普通本科、高职、不同校区和城市都有各自的条件，先选一条适合你这周的试试。
